Two clipping objectives

Weight MSE selects one clipping factor per layer by reconstruction error. Calibration logits selects both clipping factors by final output error on a separate calibration partition. Both use the same 12-factor grid from 0.45 to 1.00.

Separated data

Each seed uses a stratified train / calibration / test split. Training uses a fixed 350-epoch schedule. Test samples enter only the final evaluation. Split indices and data fingerprints accompany every model.

What the byte counts measure

Weight bytes count the actual packed arrays. Payload bytes also include float32 scales and biases. NPZ bytes measure the saved file with headers and metadata. The runtime expands packed weights to float32 for NumPy matrix multiplication, so stored compression and forward-pass speed are separate measurements.

Batch inference uses the complete test partition: 367 samples per call. Timing includes unpacking and dequantization, excludes disk loading, and records 41 measured forwards after five warmups. Measurement order: randomized round-robin across all 21 models; RNG 718. BLAS thread budget: 1.

Reproduce the experiment

Run python tinyquant.py experiment --output results --seeds 17 43 91. The directory contains packed NPZ models, split identities, selection traces, JSON metrics and CSV records.
